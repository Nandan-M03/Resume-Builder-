# ResumeCraft
Build Your Future. One Resume at a Time. 100% frontend — no backend.

## Host on GitHub Pages
1. Create a new public repo and upload everything in this folder (keep `index.html` at the root).
2. Repo → Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)` → Save.
3. Your site goes live at `https://<username>.github.io/<repo>/` in about a minute.

## Use
Build My Resume → edit on the left, live A4 preview on the right → **Download PDF** → choose *Save as PDF* in the print dialog (links stay clickable). Data auto-saves in this browser only; use Export/Import JSON to move it between devices.
